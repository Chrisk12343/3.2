# 3.2-main — Login Page

Small demo project containing a simple login page and supporting files.

## Files

- `Login.html` — the login form (open in a browser to run).
- `color.css` — stylesheet used by the page.
- `function validate().js` — JavaScript validation for the form.

## Usage

1. Open `Login.html` in your web browser (double-click or use "Open File").
2. The page uses `color.css` for styling and `function validate().js` for client-side validation.

## Notes

- Filenames are used as-is from the workspace. Rename `function validate().js` if you prefer a simpler filename.

Created for quick local testing of a login form.
